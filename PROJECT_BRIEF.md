PRODUCT
- Porch Light. Tagline (italic serif): "Leave the light on for home."
- Buy and rent homes and commercial property in India. Currency is INR only, formatted with Intl.NumberFormat('en-IN'). Short form on listings: Rs 85 L, Rs 2.4 Cr. Full form on details: 1,25,00,000. Rent: 35,000 / month. Area in sq ft. Use BHK, RERA ID, security deposit, token amount.
- Seed cities: Kochi, Kozhikode, Thiruvananthapuram, Bengaluru, Mumbai, Hyderabad, Chennai, Pune, Delhi NCR.
- Voice: calm, short, plain. No emojis anywhere. No exclamation marks.

React + Vite, Tailwind CSS, react-router-dom, framer-motion, lenis, lucide-react, leaflet + react-leaflet, @photo-sphere-viewer/core (360 tour), recharts, jspdf, react-hot-toast, react-hook-form, browser-image-compression, @fontsource fonts. Add nothing else unless essential. Use free tools only. No API keys needed to run.

ROLES: guest (logged out), user, agent, admin. Enforce in route guards and in the service layer. Role can never be changed by the person. No public admin signup.
- Guest: sees Home, Buy, Rent. Opening a property shows a "Login to view this property" overlay.

- Agent: browse; manage own listings; visits, inquiries, chat, income, reviews. Cannot buy or rent (show quiet note "Agent accounts can't book properties."). A pending agent can log in but can't publish listings until verified.
- Admin: moderates everything.

DESIGN SYSTEM
- Colors (CSS variables + Tailwind tokens): porcelain beige #F1ECE3 (background), dark gray #26262B (text, dark sections), heather purple #8F7FA8 (shapes, tints), deep purple #5E4F7A (titles, small purple text, active states), electric lemon #E6FF3D (tiny decorative markers only: logo dot, one small square, a status dot, one chart highlight. Never large areas, never text on beige).
- Text is mostly dark gray mixed with deep purple. Reference mood: beige canvas, large deep-purple serif headline, subject overlapping the headline for depth, thin top rule, tiny sparkle glyphs, outlined pill buttons.
- Fonts: Instrument Serif (display, large, tight tracking, italic words in headlines), Manrope (body), Space Mono (labels, prices, numbering). Use clamp() for fluid type.
- Shapes (reusable components, CSS border-radius/clip-path): Arch, Circle, Pill, Leaf (two opposite corners rounded), Notch, Block.
- Rules: no repeated identical card grids, no stock drop shadows, no generic AI gradients. Depth comes from layering, overlap, masks, thin 1px rules, grain, and large soft shapes. Bento grid on Home with unequal tiles in different shapes. Swiss-style spec rows (mono label left, value right). Neumorphism only on small controls on beige.
- Listing rows on Buy and Rent browse pages use a unified, repeatable property row card (PropertyRowCard) with clear 3:2 photos, Swiss spec grids, and mode-aware pricing, replacing rotating editorial shapes for scannability. Editorial shape masks remain on the Home showcase.
- Dashboards: slim text side rail (drawer on mobile), large serif page title, big serif numerals separated by thin rules instead of stat cards, ruled lists, colored text status tags. User: vertical timeline feel. Agent: ledger style. Admin: dense queue with split pane.
- Motion: framer-motion for everything (route curtain wipe in purple under 600 ms, staggered reveals, shared-element image transition from listing to details, layout animation when filters change, scroll parallax via useScroll). Lenis smooth scroll (off on touch and reduced motion). Animate only transform and opacity. Vary hover effects: image clip-path reveal or slow zoom, magnetic buttons, underline that draws in left and out right, nav sliding underline. Every hover has a tap equivalent. No auto-playing slideshows. Respect prefers-reduced-motion.
- Responsive and fast: mobile-first, works at 360, 768, 1024, 1440 px, no horizontal scroll, use dvh not vh, touch targets 44 px, lazy-load routes, paginate lists (12 per page), debounce search 300 ms. Mobile: list/map toggle, bottom-sheet filters, fixed bottom action bar on details.

IMAGES
- Never use a raw img. Use a SmartImage component: fixed aspect-ratio frame, object-fit cover, optional focal point, lazy loading (hero eager), blurred placeholder fading to sharp, alt text. Portrait photos in galleries use contain over a blurred enlarged copy so nothing is cropped badly.
- Ratios: listing 3:2, gallery 16:9, circle 1:1.
- Upload limits per property: maximum 5 photos total (combined limit across local JPG/PNG/WebP uploads and validated remote image URLs, max 5 MB each), 1 cover selection, max 2 floor plans; 360° tour (equirectangular 2:1, available exclusively for properties with verified/approved Premium status). Compress local uploads in the browser (max 2400 px long edge, WebP quality ~0.82, never upscale). Agent upload screen provides guidance, photo counter (X / 5), reorder controls, cover selection, and failed URL feedback.
- For now use free stock photos (Unsplash/Pexels direct image URLs) stored in one file src/mocks/images.js, matched to property types, so they can be swapped later. If you cannot access URLs, use simple tinted placeholder images from that same file.

PROPERTY FIELDS
Basics: title, description, listing type (sale/rent), type (house, mansion, villa, apartment, penthouse, townhouse, farmhouse, studio, plot, warehouse, office, shop, industrial), price or monthly rent, negotiable, ownership, RERA ID, possession status, age, available from, address, locality, city, state, PIN, map pin as lat/lng.
Residential: bedrooms, bathrooms, balconies, floor, total floors, facing (all 8 compass directions: North, North-East, East, South-East, South, South-West, West, North-West), furnishing (3-button selector: Fully Furnished, Semi-Furnished, Unfurnished), built-up/carpet/plot area, parking, pool (private/shared/none), garden, gym, lift, power backup, water supply (Corporation Supply, Borewell + Municipal, Well, 24/7 Treated Water), security, gated, pets allowed.
Floor fields rule: floor level and total floors apply conditionally by property classification. Unit-style buildings (apartment, studio, penthouse, office, shop, commercial) require Unit Floor Level and Total Floors. Standalone properties (house, villa, mansion, townhouse, farmhouse, warehouse, industrial) require only Total Floors/Stories and omit floor level. Plots and land omit floor fields entirely.
Price negotiation rule: when a listing is marked "Price is open to private negotiation", all public views (cards, map pins, search results, and Property Details) display "Price on request" or "On Request" without exposing numeric pricing or calculator projections. Fixed-price rules remain unchanged for non-negotiation listings.
Rent only: deposit, maintenance, min lease, notice period, preferred tenants.
Access: road type, road width, paved, nearest city + distance + travel time, distance to bus stop, railway, airport, hospital, school, market.
Commercial/land extras: ceiling height, loading docks, truck access, power load (warehouse); frontage, floor (office/shop); zoning, boundary, road frontage (plot).
Field applicability and editable property identity: Single source of truth `getPropertyFieldApplicability(type, listingType)` enforces conditional field display, validation, and sanitization across Add Property, Edit Property, and Property Details (suppressing irrelevant/stale rows). In Edit Property mode, core compliance fields (Property ID, Transaction Type, Property Classification, Location/Coordinates, RERA ID, and Legal Ownership) are strictly read-only and preserved from original records, restricting editing to permitted operational attributes (price, specs, amenities, media).
Premium rule: Premium tier status is granted exclusively through verified promotion approval or Admin flag (independent of property price or typology). Premium status unlocks the 360° virtual tour and the "Premium" badge across listings and Property Details. Non-premium listings display a Porch Light styled upgrade callout on Property Details.
Agent Rating rule: Agent ratings are star-only (integers 1–5), directly tied to successful completed property transactions (token advances or rental deposits with `status === 'completed'`). Visit-only bookings and pending/failed/cancelled/refunded payments are strictly ineligible. A refund immediately invalidates the rating (`status: 'ineligible'`) and removes it from the agent average without deleting the audit record. No written reviews, comment text, or reply workflows exist. Unrated agents display "No ratings yet" (never 0 stars). Ratings can be submitted immediately upon checkout confirmation, or later from the agent card on authorized Property Details and the user dashboard payments/properties pages; re-submitting updates the existing transaction rating record.
